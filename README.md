# pre-entrega-limpieza-pandas
Ejercicio curso data scientist1
Este proyecto contiene la limpieza de un dataset de ventas que presentaba problemas técnicos como nulos en categorías, registros duplicados, fechas mal formateadas y valores de venta no numéricos. Se aplicaron técnicas de imputación (mediana, modas) y eliminación de duplicados, además de análisis agrupados mediante groupby.
